# Projeto Focus

Aplicação web desenvolvida como projeto acadêmico para a disciplina de **Desenvolvimento Front-End para Web**, com o objetivo de ajudar na organização de tarefas e na gestão de produtividade do dia a dia.

## Tecnologias Utilizadas

* **HTML5** (Semântico e estruturado)
* **CSS3** (Estilização modular com CSS externo)
* **Git e GitHub** (Controle de versão e colaboração em equipe)

## Estrutura do Projeto

O projeto é composto por 6 páginas principais, construídas sem uso de JavaScript (foco total em HTML e CSS):

* `index.html` - Página inicial e painel geral.
* `tarefas.html` - Listagem e filtros de tarefas.
* `cadastrar.html` - Formulário para cadastro de novas atividades.
* `concluidas.html` - Visualização das tarefas finalizadas.
* `produtividade.html` - Painel de desempenho e progresso geral/por categoria.
* `sobre.html` - Informações sobre o projeto e desenvolvedores.

## Como Executar o Projeto

Como o projeto utiliza apenas **HTML e CSS** puro (sem dependências ou necessidade de instalação de Node.js/frameworks), rodar ele na sua máquina é muito simples:

1. **Clone o repositório** ou baixe os arquivos para o seu computador.
2. Abra a pasta do projeto no **VS Code**.
3. A forma mais prática de rodar é usando a extensão **Live Server** no VS Code:
   * Clique com o botão direito em cima do arquivo `index.html`.
   * Selecione **"Open with Live Server"**.
4. O navegador abrirá automaticamente na página inicial do projeto (`index.html`) e você poderá navegar por todas as abas.
